# 冷链交接复核场景

北岸冷运每十分钟上传配送探头记录，滨江仓储在09:30签收。质控员必须判定超温属于运输还是入库等待，并区分探头丢包造成的未知时段。不能仅用最高温或超限采样个数决定责任。

随项目交付八个配送批号，每批六个标准采样；脏样例附带重复、温标混合、失效探头、错误时间与冲突温度。先在轨迹采信查看来源，再在探头校准确认单位，交接时间轴核对责任归属，超温积分查看超限分钟与热暴露，质量隔离保留拒收证据，责任对账复核守恒，批次复核记录版本。

标准样例总覆盖480分钟，40至60分钟缺测导致160分钟未知。北岸冷运每批超温热暴露为51.428571°C·min，滨江仓储为10°C·min。系统保留未知状态，复核动作只确认当前证据，不能代替缺失的测量。

校准室发现P1当天漂移后补发09:00–09:40修正段（偏移−0.8°C）。裁决：先采用可证实部分。八个批号中只有00002、00003、00004窗口内证据完整，按修正段重算入账；其余五批保留旧账，窗口内每方30或10责任分钟标记待证实，不按推测温度入账。复核页面逐批说明处置、影响责任分钟与依据；重复提交同一修正复用批次，应用失败恢复旧版，原始采样与已复核记录全部保留。
